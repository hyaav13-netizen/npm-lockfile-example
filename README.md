# npm lockfile example

This GitHub Pages project hosts a small, versioned package archive for an npm shrinkwrap and lockfile example. The archive contains no installation scripts or runtime dependencies.

Archive URL: `https://hyaav13-netizen.github.io/npm-lockfile-example/good-0.1.0.tgz`.

The companion package `@hya_a/remote-integrity-example@0.1.0` pins this archive and its SHA-512 digest in `npm-shrinkwrap.json`.
